# Task 3: Container Monitoring

## Description:
Monitor Docker container CPU and memory usage with timestamp.

## Steps:
1. Created monitoring script
2. Logged CPU and memory usage
3. Added timestamp
4. Automated using cron job

## Commands:
docker stats
crontab -e

## Output:
Logs stored in /opt/container-monitor/logs
